# 📘 DSA-2 Practicals (C Programming)

This repository contains a complete collection of **Data Structures and Algorithms (DSA-2) practical programs** implemented in **C language**.
All programs are written with a focus on **clarity, correctness, and structured logic**, making them ideal for academic use and exam preparation.

---

## 🚀 Features

* Clean and structured C programs
* Focus on **recursion and dynamic programming concepts**
* Covers **trees, graphs, heaps, and advanced algorithms**
* Ready-to-run and tested implementations
* Useful for **AKTU / university practical exams**

## ▶️ How to Run

1. Clone the repository

   ```bash
   git clone https://github.com/PrakC7/dsa.git
   ```

2. Navigate to the folder

   ```bash
   cd your-repo-name
   ```

3. Compile any program

   ```bash
   gcc filename.c -o output
   ```

4. Run the program

   ```bash
   ./output
   ```
